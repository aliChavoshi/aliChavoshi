## Open source

### [Ecommerce-Microservice](https://github.com/aliChavoshi/Ecommerce-Microservice)

A full microservice e-commerce platform on **ASP.NET Core 9** and **Angular 20**. The diagram follows real requests through the system: browsing the catalog, signing in, a gRPC discount lookup and a checkout event over RabbitMQ.

<a href="https://github.com/aliChavoshi/Ecommerce-Microservice">
  <img src="assets/ecommerce-dark.svg#gh-dark-mode-only" width="100%" alt="Ecommerce-Microservice architecture: the Angular client calls the Ocelot API gateway inside a Kubernetes cluster. The gateway uses Identity Server and routes to Catalog.API with MongoDB, Basket.API with Redis and Ordering.API with SQL Server. Basket.API calls Discount.API with PostgreSQL over gRPC and publishes checkout events to RabbitMQ, which Ordering.API consumes."><img src="assets/ecommerce-light.svg#gh-light-mode-only" width="100%" alt="Ecommerce-Microservice architecture: the Angular client calls the Ocelot API gateway inside a Kubernetes cluster. The gateway uses Identity Server and routes to Catalog.API with MongoDB, Basket.API with Redis and Ordering.API with SQL Server. Basket.API calls Discount.API with PostgreSQL over gRPC and publishes checkout events to RabbitMQ, which Ordering.API consumes.">
</a>

- **Deployment:** Docker and Kubernetes for deployment and scaling
- **Security:** Identity Server for authentication and user management
- **Communication:** RabbitMQ and gRPC between services, Ocelot and Nginx as API gateway
- **Data:** SQL Server, MongoDB, PostgreSQL and Redis, each where it fits the domain
